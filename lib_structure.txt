  2. LEGACY SCREEN

     This appears to be a legacy/alternate paywall. The current paywall implementation
     is lib/core/widgets/paywall_bottom_sheet.dart (bottom sheet pattern).

  3. PREMIUM GATE PATTERN
     PaymentService.requirePremium() is wired into home_view.dart and
     show_apartment_details_view.dart. Free users see PremiumLockOverlay (blur)
     and are redirected to paywall_bottom_sheet.dart on interaction.

  4. AUTH FLOW ORDER
     SplashView → ChooseLanguageView → OnBoardingView → ChooseAuthMethodView
     → (SignUpView | SignInView) → VerifyEmailView → CompleteProfileView
     → LogicView → MainView

  5. SEARCH VS HOME FILTER
     There are two separate search/filter implementations:
     · home/widget/search_bar_widget.dart + filter_bottom_sheet.dart
